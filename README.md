# Houston Air Duct Cleaning

Fifteen-location Houston site for air duct and dryer vent cleaning.

## Pages

- `/` home
- `/services`
- `/about`
- `/locations`
- `/contact`
- `/locations/[street-slug]` one page per address

## Local

```bash
npm install
npm run dev
```

## Deploy

Vercel. Set `NEXT_PUBLIC_SITE_URL` to the live domain.
